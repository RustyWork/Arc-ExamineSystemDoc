## General

- **AudioSource** → Here you can add the <span style={{color: '#ff8011'}}>**Audio Source**</span> that you are using in **Examine Manager** or add a new one.

- **Sound** → Here you can add an <span style={{color: '#ff8011'}}>**Audio Clip**</span> that you want to play.

- **Volume** → Here you can change the volume of your sound.

- **OneTimePlay** → This feature could be very helpful if you want to play the sound only for a single time.
